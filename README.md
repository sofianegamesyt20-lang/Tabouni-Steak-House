# Tabouni Steak House

A premium, modern steakhouse website featuring bold red and white branding with sophisticated animations and luxurious design.

## Features

- **Hero Section**: Full-screen hero with animated logo, gradient text effects, and smooth scroll indicators
- **About Section**: Interactive stats counter with animated progress rings and image gallery
- **Menu Showcase**: Filterable menu with categories, featured items, and modal details
- **Experience Section**: Parallax background showcasing quality, atmosphere, and service
- **Gallery**: Masonry grid layout with lightbox and category filters
- **Reservations**: Booking form with floating labels and success animation
- **Testimonials**: Auto-rotating carousel with 5-star ratings
- **Contact & Location**: Interactive map, opening hours, and social media links
- **Footer**: Newsletter subscription and Instagram feed

## Design Highlights

- Custom red/white color scheme (#DC0000)
- Playfair Display serif headings
- Inter sans-serif body text
- Smooth scroll-triggered animations
- Hover effects with red glow shadows
- Glassmorphism elements
- Mobile-responsive design
- Performance optimized

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React Icons

## Getting Started

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
